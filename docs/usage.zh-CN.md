# KataGhost 使用说明

点选棋盘交叉点，再按「确认落子」。确认前可以改选。「虚招」用于停一手。「形势」显示地盘归属估计、分差和提子统计，点「返回」退出。

棋步导航旁的「候选」开关可快速控制候选标记。字母按搜索排名排列，颜色表示相对首选的胜率损失。长按棋盘上的候选点可预览后续变化，推荐虚招时，字母显示在「虚招」按钮旁。

仅黑棋由 AI 自动落子时，分析区显示白棋胜率，其余情况显示黑棋胜率。落子前后只要任一方达到 95%，浮动提示就显示分差变化；也可以在设置中让每一手都显示分差变化。

AI 虚招会在棋盘上提示，提示消失后进入下一手。连续两次虚招会进入结算，显示胜方、分差、盘面棋子和提子数量。轻点卡片即可关闭。

可用棋步导航和「变化树」回看棋局及分支。右上角菜单提供 SGF 导入、导出、清空棋盘和设置。

设置中的「AI 对手」分别控制黑棋、白棋自动落子，并提供独立的难度设置。「引擎」区域的分析搜索预算用于候选推荐与复盘。「棋盘」区域可设置坐标和候选标记。详见[对局设置](game-settings.md)。
