# KataGhost design assets

The current Android interface is implemented in Jetpack Compose and illustrated by the [emulator screenshots](../docs/images/) and [interface guide](../docs/android-ui.md).

The [launcher foreground SVG](icon/ai-foreground.svg) is the design source for the [Android adaptive icon foreground](../app/src/main/res/drawable/ic_launcher_foreground.xml). The other icon files are original design exports.
