# KataGhost design assets

The current Android interface is implemented in Jetpack Compose and illustrated by the [emulator screenshots](../docs/images/) and [interface guide](../docs/android-ui.md).

The [launcher icon master](icon/kataghost-icon.png) depicts a wooden Go board with a luminous marker at the suggested move. Android uses a padded raster layer for adaptive masks, a monochrome vector for themed icons, and density-specific WebP assets for the standard and round icons.
